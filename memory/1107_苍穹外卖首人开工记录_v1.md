## 环境说明

- 本机当前只有 JDK 25，项目代码按 Java 17 编译；正式联合开发建议统一安装 JDK 17。
- 本机没有 Docker，因此 MySQL、Redis 和 MinIO 的真实容器联调未执行。
- 后端集成测试使用 H2 内存数据库，Redis 使用测试替身。
- Vue2 和 Vue CLI 已停止维护，构建时会出现依赖版本及包体积警告，但不影响当前产物生成。
